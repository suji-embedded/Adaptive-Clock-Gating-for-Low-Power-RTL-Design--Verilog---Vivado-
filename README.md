 Adaptive Clock Gating for Low Power RTL Design

 Overview
This project implements a lookahead-based adaptive clock gating technique to reduce dynamic power in synchronous systems.

 Features
- Gray code addressing to reduce switching activity
- Address change detection for adaptive clock control
- 64x8 ROM design
- BUFGCE-based glitch-free clock gating
- Lookahead gating using negedge control

 Tools Used
- Verilog HDL
- Xilinx Vivado

Files
- proposed.v → Main design  
- tb.v → Testbench  
- const1.xdc → Constraints  

 Result
Reduced unnecessary clock switching and improved power efficiency.
